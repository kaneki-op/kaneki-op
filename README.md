### What I've built

**GigWork** — a full-stack platform connecting event organizers with gig workers in Bangalore. React + Vite on the frontend, Node/Express and MongoDB on the backend, with real-time chat over Socket.io, JWT auth, and geofenced check-ins (Haversine formula to confirm a worker is actually on-site). Also has a reliability scoring system for workers and an admin moderation console.
[Live demo](https://gig-work-mu.vercel.app) · [Repo](https://github.com/kaneki-op/GigWork)

**FlexPlan** — an Android productivity app, written in Kotlin with SQLite for local storage.

**WeFo** — a weather app pulling live data from a public REST API.

**Custom Unix Shell** — a shell built from scratch in Node.js, because I wanted to understand what a terminal is actually doing.

**Anime Blog** — a simple blog project, mostly an excuse to practice clean frontend layout.
